# Research records

Investigation-only work ("scout" tasks, see `.crew/README.md`) lands here as
standalone reports - never as code, never pushed to a branch.

Each record carries three things:

1. **Method** - how the question was investigated.
2. **Measurement** - what was actually observed, with numbers where possible.
3. **Eviction rule** - the condition under which this record leaves `research/`,
   typically "harvested into a decision or an issue".

Naming: `<topic>.md`, lowercase-hyphenated (for example `agentic-workflow.md`).

A record is evidence for a decision; once the decision is written down elsewhere,
the record moves on per its eviction rule. Records are not documentation - they do
not describe the system, only the inquiry that informed it.
