Key Decisions

Decision Rationale
Unified tiers/ directory The deterministic and semantic docs described overlapping aspects of the same cascade. A single directory with focused files eliminates duplication and makes the tier relationships explicit.
4-layer cascade as the organizing principle The grading system has exactly 4 evaluative layers (execution accuracy → structural → literal → semantic) plus capture as pre-cascade. This maps cleanly to the Diátaxis explanation category and gives readers an immediate mental model.
Keep calibration, replay, authoring, disagreements as-is These directories are already well-organized, single-topic, and don't overlap with the tiers. Their internal structure is clean.
Move V6 audit and t0027 to archive These are historical evidence, not living documentation. The archive/ directory is the correct home for dated, non-active docs.
Keep docs/how-to/evaluate.md as a pointer It already serves as the thin entry point from the docs/ side. No change needed beyond updating its internal links.
Preserve IMPLEMENTATION_PLAN.md and Instrument_Report.md These are dated but active planning artifacts. They document progress toward a target and provide historical baseline context. Not duplicated elsewhere.
