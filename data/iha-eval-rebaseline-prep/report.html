Fixes Applied in This PR

Fix 1

Trace score summary metadata

evals/writeback.py

After writing individual Langfuse scores, write_scores() now stamps a judge_scores summary dict onto the trace metadata, plus a calibration_version provenance field.

+ metadata["judge_scores"] = {
"seam1_routing/Tool Correctness": {score, reason},
"seam1_routing/Argument Correctness": {score, reason},
"seam2_nl_to_sql/SQL Schema Quality": {score, reason},
"seam3_synthesis/Task Completion": {score, reason},
"seam3_synthesis/Honesty": {score, reason}
+}
+ metadata["calibration_version"] = "calibration_v8.yaml"
Fix 2

Strengthened JUDGE-1 annotation

evals/semantic.py

The original annotation only mentioned English patterns. Expanded to include explicit Vietnamese free-text hedge patterns ("Tôi tìm thấy N…") and require the hedge to appear before or interleaved with the list, not merely as an afterthought.

Before:
"...asserts a definitive list such as 'I found N jobs with X benefit' without any hedge is a FAIL."
After:
"...In Vietnamese, phrases like 'Tôi tìm thấy N công việc…' presented as a flat enumerated list without a hedge are also FAIL. The hedge must appear before or interleaved with the list, not merely as an afterthought or disclaimer at the end."
Fix 3

Calibration version propagation

evals/score.py

Updated the write_scores() call site to pass calibration_version=CALIBRATION_VERSIONS["v8"].name so every trace carries its calibration provenance.

Fix 4

Test compatibility

tests/evals/test_score.py

Updated the fake_write_scores fixture to accept the new calibration_version keyword argument. All 374 tests pass.
